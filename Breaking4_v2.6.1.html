Breaking 4 comme application

Installer Breaking 4

Vérification du mode d’ouverture…

Breaking 4 peut être ajouté à l’écran d’accueil et s’ouvrir ensuite en plein écran, comme une application.

Sur iPhone / iPad

  1. Ouvre l’adresse de Breaking 4 dans Safari.
  2. Touche le bouton Partager.
  3. Choisis Sur l’écran d’accueil.
  4. Valide avec Ajouter.

Ensuite, lance Breaking 4 depuis son icône sur l’écran d’accueil. Le fichier HTML enregistré dans l’app Fichiers ne peut pas être transformé directement en application par iOS.

Fonctionnement hors ligne

Après une première ouverture depuis l’adresse web, l’interface principale est mise en cache. Breaking 4 peut alors s’ouvrir sans connexion pour consulter et modifier le calendrier et la bibliothèque.

Une connexion reste nécessaire pour Intervals.icu et, lors du premier usage, pour charger le module d’import Excel.

Données personnelles

La bibliothèque, le calendrier et les paramètres restent enregistrés dans le stockage local de cette installation. Utilise régulièrement Exporter toutes les données pour disposer d’une sauvegarde.

La clé API Intervals.icu n’est pas intégrée au fichier partagé.

Intervals.icu — Connexion

Aucune connexion testée.

Sécurité : la clé API est enregistrée uniquement dans le stockage local de ce navigateur et n'est pas incluse dans les sauvegardes JSON. Pour une application partagée à plusieurs personnes, il faudra passer ensuite à OAuth.

Envoi des séances

La v2.5 conserve la syntaxe Workout Builder validée : Z1 Pace pour les phases faciles, allure absolue pour les efforts et Press lap pour les récupérations manuelles.
Important
Une séance doit être enregistrée dans la bibliothèque avant d'être planifiée. Les jours de repos sont envoyés comme notes. Pour une récupération manuelle, Intervals.icu exige une durée estimative pour calculer la charge : la v2.5 utilise 1 min par défaut, ajoute Press lap et cible Z1 Pace en course à pied. Cette commande est surtout documentée pour Garmin ; son transfert vers COROS doit être testé.
